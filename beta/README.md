# 内测版（公测）· 剧核 DramaCore

> ⚠️ 内测版用于验证「更快 + 效果更好」的新链路，**不是正式版**。
> 正式版（昨晚测试通过的稳定版）见仓库根目录 / Release `v0.2.0-internal`。

## 版本信息
- 频道：内测（public beta）
- 版本：`0.3.0-beta.1`
- 基础：正式版 `v0.2.0-internal` + ROUND83/84 安全与稳定性修复
- 特性：纯 t2v、无素材图链、2×长段、无转场/硬字幕、单次封装

## 两个内测工作流
| 文件 | 段数×时长 | 适用 |
|---|---|---|
| `workflows/内测版_高质量_2x15s.json` | 2×15s ≈ 30s | 画质优先（对齐外部高质量工作流） |
| `workflows/内测版_极速_2x10s.json` | 2×10s ≈ 20s | 速度优先 |

两者都：t2v / 生成素材图=关 / 转场=无 / 字幕=无 / 自动返工=关 / Refine=关 / 1376×768 / 8步 / 24fps。

## 使用
1. 解压内测版包，覆盖/放入 ComfyUI `custom_nodes/bettercomfyui_comfy`（与正式版同一插件目录即可）；
2. 重启 ComfyUI，Ctrl+F5；
3. 打开 `beta/workflows/` 下的内测版工作流（ComfyUI 工作流菜单或拖入）；
4. 测试并记录：耗时、显存、接缝、人物一致性、口型。

## 回退正式版（重要）
- 内测版报错/效果回退 → **重新打开正式版工作流**：
  - `bettercomfyui_comfy/workflows/【新版】剧核_单节点_剧本到成片_真实参数版_20261024.json`
  - 或 `…快速4步版…json`
- 正式版文件未改动；不需要卸载/重装；
- 如果整个内测包导致启动失败：把 `beta/` 目录移走/删除，重启 ComfyUI 即回到正式版行为。
- 代码改动均带 `.bak_r83_*` / `.bak_r84_*` 备份，可回滚。

## 不要做的
- 不要把内测版默认设为生产/交付版本；
- 不要在未 A/B 的情况下用内测版替代正式版出片；
- 不要删正式版工作流文件。
