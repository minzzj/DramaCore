## 三、探测方法修正（避免假结论）

第一版把 `DNNodes` / `Director` / `ChainDirector` 全判成「导入失败」—— **假阴性**：

```
ModuleNotFoundError: No module named 'folder_paths'
ModuleNotFoundError: No module named 'comfy'
ImportError: cannot import name 'PromptServer' from 'server'
```

这三个都是 **ComfyUI 自己的模块**，裸进程当然没有，
而这些包**此刻正在 ComfyUI 里跑着**（DNNodes 4 个节点、Director 11 个、ChainDirector 4 个）。

判据已改为：

* **已装的** → 直接查运行中 ComfyUI 的 `/object_info`（最权威）；
* **备用的** → 裸进程导入，缺 ComfyUI 内部模块标「需运行时判定」，**不判失败**。

只有「缺第三方依赖 / 语法错误」才算真失败。
脚本：`scripts/probe_reserve_packs.py`

## 四、新增：流程图默认值一致性守卫（10 条）

把 `文档/流程图-总.txt` 里写明的默认值与 `config/default.yaml` 做成**断言**，
每条注明流程图出处（`C3` / `JP1` / `JP4` / `ENC3` …）。

**为什么值得做**：默认值漂移没人会发现，用户会看到
「文档说 10 秒、实际跑别的值」。改动默认值时这条测试会红，
提醒「改之前先确认是不是有意为之」。

覆盖四组：

| 组 | 覆盖的流程图节点 |
|---|---|
| 提示词 | `C3` 输出语言中文、`C4` 结构化JSON、`C5` 按镜头、素材注入开启、名称归一化开启 |
| 素材生成 | `GP1` 1024、`GP2` 25 步、`GP3` DPM++ 2M Karras、`GP4` CFG 7、`GP6` 批量 4、`G4` 每类 9 |
| 素材审核 | `H2` 3 轮、`H3` 10 分钟、`H4` 切模型、`H5` 四维度、`H6` 阈值 70、`N` 最高分兜底、新版本必重审 |
| 导演台 / 视频审核 / 封装 | `JP1`–`JP7`、`R2` 阈值 70、CNT2/CNT3 上限 3、最大级联深度、`ENC2`–`ENC6`、`OUT4` 封面 |
| 全局 | `Z3` 配置导入导出、`Z4` INFO、`Z5` 记录所有手动与自动切换、检查点、技术重试上限 |

**另有一条语义隔离守卫**：CNT2/CNT3 必须在 `video_review`，
技术重试必须在 `global_` —— 防止有人图省事把两类计数合并
（任务书 §F 规则 6：技术重试**不消耗** CNT2/CNT3）。

**结果：10/10 通过** —— 配置默认值与流程图**逐条一致**。
