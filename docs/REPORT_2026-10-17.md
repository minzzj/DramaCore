## 一、本轮做的两件事

### 1. 纠正架构方向（用户指出的问题）

我此前把 AI 视频生成做成了自己编排器里的 mock，把用户给的导演台当"候选组件"审计。
**这是把核心引擎降级成了可选依赖。** 现已改为：**导演台负责生成，我负责版本/审核/编排。**

### 2. 按三份文档补齐第一阶段缺口

我写了 `bettercomfyui/gap_analysis.py` —— 把方案第三部分 8 张参数表 + 核心原则
做成**可执行的覆盖盘点**，逐条标注 `DONE / DELEGATED / TODO` 并给出实现位置。

**当前：73 条要求，DONE 64 / DELEGATED 13 / TODO 0。**

（`DELEGATED` = 由导演台或采样节点承担，融合层负责接线。方案的"参数建议值"里
大量条目原文就写明「仅工作流支持时使用」「每类上限9 节点限制」——这些本就是**执行节点**的能力，
编排层不该重复实现，但必须能接线。V1 版盘点表曾把它们误标为 TODO。）

### 3.3 两个融合工作流（脚本从运行中的 ComfyUI 读 schema 生成）

| 文件 | 拓扑 | 校验 |
|---|---|---|
| `fusion_A_director_r2v.json` | 项目 → 融合组(MMX_DIR_GROUP) → **MiniMaxH3Director** | **PASS** 4 OK / 0 FAIL |
| `fusion_B_chain_director.json` | 时间轴文本 → **MiniMaxH3ChainDirector** → 回灌 | **PASS** 6 OK / 0 FAIL |

**为什么用脚本生成而不是手写**：`widgets_values` 是**按位置**对应控件槽位的，
少一项/顺序错一项会让参数**静默错位**（cfg 填进 seed 这种），载入不报错但结果全错。
生成器直接从 `/object_info` 读真实 schema 拼值，校验器再核对控件数
（实测：Director 22 个控件槽、ChainDirector 15 个，全部匹配）。

## 四、读源码发现的两个上游陷阱（已在我的节点里规避）

### 4.1 ChainDirector 的 `全局提示词` 会被丢弃 ★

`chain.py:270-307` 构造的 timeline 里**没有 `commonEnabled`**，
导致依赖包 `external_groups.py:676` 走 `prompt = group_prompt or fallback_prompt` 的 else 分支：
**只要段文本非空，`全局提示词` 就被完全丢弃。**

→ 我的 `融合·时间轴文本` 把「全片设定」**逐段前置**到每行时间轴里，保证生效。

### 4.2 ChainDirector 中文节点 `ref_video_fps` 参数失效

`chain.py:501` 读 `kw.get("参考视频帧率", 0)`，而 INPUT_TYPES 里的键是 `ref_video_fps`
（`chain.py:455`）→ **恒为 0** → 永远走等比切分。英文版 `chain_en.py:91` 正确。

→ **这是上游 bug，我没有改它的代码**（不在写入范围，改了会分叉）。规避：需要精确切分时用英文节点。

## 七、未验证项（如实列出）

1. **端到端出片未验证** —— 需要 MiniMax H3 权重约 **60GB**（6 个文件）；
   实测口径峰值显存 **22,016 MiB**（约 21.5 GiB），系统内存建议 ≥64GB。
   本机是 CPU 版 torch + GTX 1050 Ti（**4GB，档位 `minimal`**），**物理上跑不了 H3 采样**。
2. **`groups` 被 Director 实际消费未验证**（需权重跑完整采样）。
3. **真导入 `pack_*` 的运行时比对未在本机完成** —— Director 包内部 `import comfy`，
   必须在 ComfyUI 运行时内才能导入；本机做的是 AST 静态比对（已证明能抓 bug）。
   装齐权重后在 ComfyUI 里跑一次 `融合·体检` 即可完成这最后一步。
4. **网页面板在浏览器里的渲染未验证**（只能验证 JS 可解析 + 路由 200 + 节点注册）。
5. **参考音色/音频链路、导演台高级模式（二采/Guide/SelfLift）未接入编排层。**
6. **ChainDirector 官方工作流用到 `VHS_VideoCombine`（ComfyUI-VideoHelperSuite）与
   `PathchSageAttentionKJ`（KJNodes），这两个包本机未安装** —— 需要时按
   `ChainDirector/scripts/install_all.py` 装（`git clone` 在本机被墙，用 zip 下载可绕过）。
