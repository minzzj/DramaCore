## 一、探测方法的修正（先说这个，因为它影响可信度）

第一版探测把 `ComfyUI-DNNodes`、`MiniMaxH3Director`、`ChainDirector`
全判成了「导入失败」—— **那是假阴性**：

```
ModuleNotFoundError: No module named 'folder_paths'
ModuleNotFoundError: No module named 'comfy'
ImportError: cannot import name 'PromptServer' from 'server'
```

`folder_paths` / `comfy` / `server.PromptServer` 都是 **ComfyUI 自己的模块**。
裸进程里当然没有，但这些包**此刻正在 ComfyUI 里正常跑着**。

所以判据改成两条：

| 情况 | 判据 |
|---|---|
| **已安装**的包 | **直接查运行中的 ComfyUI**（`/object_info`，按 `python_module` 反查）—— 最权威 |
| **备用**的包 | 裸进程导入；缺 ComfyUI 内部模块标为「需运行时判定」，**不判失败** |

只有"缺第三方依赖 / 语法错误"才算真失败。脚本：`scripts/probe_reserve_packs.py`。

## 三、**最重要的发现**：剧本拆解的两个巨人找到了

愿景 §15 那条断链（剧本 → 人物/场景/物品/分镜提示词 + 视频提示词），
答案不是我那套 `prompt/` 模块，而是这两个**已经在本地躺着**的巨人：

### `ComfyUI-Storyboard-LLM` → `StoryboardNode`

节点显示名：**Storyboard Generator (DeepSeek)**

```
输入 required: chapter_text（小说章节文本, multiline）, save_json（BOOLEAN）
输入 optional: custom_prompt（自定义提示词模板，留空用默认）, model（deepseek-v4-flash / deepseek-v4-pro）
输出: image_prompts, video_prompts, dialogues      ← 图提示词 / 视频提示词 / 对白
FUNCTION: generate_storyboard     CATEGORY: storyboard
```

**`image_prompts` + `video_prompts` 正是愿景 E1–E4 与 E5 的分法。**

### `ComfyUI-DeepSeek-API-connector` → `DeepSeekPromptConnector`

```
输入 required: api_key, model, temperature, max_tokens,
               output_language,        ← 愿景要的「输出语言默认中文」
               target_model, prompt_style,
               system_prompt_mode,     ← 系统提示词模式
               custom_system_prompt    ← **素材清单从这里注入**
输入 optional: text
输出: prompt, preview
FUNCTION: generate_prompt
```

`system_prompt_mode` + `custom_system_prompt` 就是**注入素材清单的入口** ——
而注入素材清单正是我这层唯一不可替代的价值（愿景：增量素材更新必须由程序
做确定性注入，不能让 AI 判断）。

### 因此正确的接法是（**站在巨人肩膀上，不是自己再写一个**）

```
小说章节文本
   ↓
[Storyboard Generator (DeepSeek)]   ← 巨人：调 DeepSeek 拆剧本
   ↓ image_prompts / video_prompts
[我的适配层]                        ← 注入素材清单 + 结构校验 + 中文标签归一化
   ↓
[融合·一体化导演台] → MMX_DIR_GROUP
   ↓
[MiniMaxH3Director]                 ← 巨人：出片（尾部22帧原生）
```

对比我原本想做的（暴露自己那套 `prompt/`）：**同样是接一个节点，
但用巨人就多得了 DeepSeek 的真实调用、模型选择、多语言输出**，
而我只补真正缺的那块（确定性素材注入 + 校验）。

## 四、为什么还没有安装

1. 你明确说过「**以后不要改代码了**」—— 安装会改你的 ComfyUI 环境；
2. 这两个包**需要 API 密钥**才能跑，而本项目规定
   **不得把真实密钥写进配置与文档**，所以装了也只能看到、连不上；
3. 它们的 `INPUT_TYPES` 和导入我都验过了（干净、可调用），
   **安装是一个文件复制、随时可撤销** —— 等你一句话我就装。

### 装上之后的验证计划（已想好）

1. 重启 ComfyUI，确认仍正常启动（**最重要的回归**）；
2. 在 `/object_info` 里确认两个节点注册；
3. 用**桩传输层**跑一次适配层（不花你的 API 额度、不联网），
   验证素材清单能注入进 `custom_system_prompt`、输出能被解析成导演组；
4. 真实 DeepSeek 调用留给你配好密钥后自己按 Queue。
