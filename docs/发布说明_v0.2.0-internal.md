# v0.2.0-internal 发布说明

发布日期：2026-10-25
许可：CC BY-NC-SA 4.0（允许下载/修改/非商业再分发；修改后须同许可开源；禁止商用）

## 这版最重要的变化

1. **系统提示词 V3.0「契约对齐」成为唯一系统提示词**
   - 文件：`bettercomfyui/prompt/data/h3_v3_contract.txt`
   - 覆盖：契约红线、可拍摄剧本、三字段/镜头语法、对白口型、声音三层、素材图、片段库、JSON Schema、自测用例。
2. **移除 colorfix 自动调色**
   - 不再逐段强行拉到固定亮度/饱和度；保留模型自然光影。
   - 光影按场景决定：白天自然明亮、夜晚自然偏暗（保留光源与暗部细节）、密室可低照度。
3. **活人感**
   - 真实皮肤纹理/自然肤色/柔和光影过渡/呼吸眨眼等微动作；禁止僵硬、塑料、CGI 平滑感。
4. **前端自动兼容**
   - 旧工作流参数值自动修复；版本化 JS（v016）避免浏览器缓存；左下角显示版本徽标。
5. **完整工作流**
   - 快速 4 步版 / 真实参数版（详见 `docs/工作流说明_完整工作流.md`）。
6. **风格为示例，必须自行修改**
   - 节点「统一风格」默认值是示例；系统提示词 PART C · C1 风格锁也是示例模板，请按项目替换。

## 升级步骤

1. 更新 `bettercomfyui/` 与 `bettercomfyui_comfy/`；
2. 复制 `config/user.yaml.example` → `config/user.yaml`（不要提交真实 Key），确认 `system_prompt_template: h3_v3_contract`；
3. 重启 ComfyUI（`BETTERCOMFYUI_HOME=<repo>`）；
4. 浏览器 Ctrl+F5 后重新打开【新版】工作流；
5. 把「统一风格」改成你的项目风格，并检查/替换 C1 风格锁。
