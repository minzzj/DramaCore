# 自定义风格与系统提示词

> ⚠️ **默认值是示例，请按你的项目自行修改或替换。**

## 1. 节点「统一风格」（推荐入口）

节点参数「统一风格」默认：
`电影感，真实自然，自然光影，正常曝光，场景自适应`

这是**示例**。请改成你的项目风格，例如：
- 都市甜宠：`明亮清新，自然肤色，柔和逆光，轻喜剧节奏`
- 悬疑夜戏：`低照度，硬光比，冷色阴影，保留暗部细节`
- 纪录片：`自然光，真实皮肤纹理，手持呼吸感，低饱和但不灰`

## 2. 导演台面板

打开导演台节点 →「提示词」面板：
- 默认加载 `h3_v3_contract`（V3.0 唯一提示词，37,457 字）；
- 可点「加载 V3.0 唯一提示词（推荐）」，或「手动编辑（高级）」替换全文后保存为面板默认。

## 3. 系统提示词 C1 风格锁

`bettercomfyui/prompt/data/h3_v3_contract.txt` 的
`PART C · C1 风格锁（受控词表，整行原样使用）` 是**示例模板**，
部署到新项目时请把风格锁替换成你项目的风格词，不要原样照搬。

## 4. 注意

- 不要把 Token/Key 写进风格词、系统提示词或工作流；
- 修改系统提示词后，保存为面板默认并重启/下次运行生效；
