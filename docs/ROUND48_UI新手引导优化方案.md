# ROUND48/49 UI 优化与可测试性改造：用户审批点对照

> 依据用户 2026-10-18 17:28 反馈整理。**已开始实现（用户已给出采纳点）**。

## 一、用户反馈的问题（必须修）

1. **看不到明显的基本输入窗口/输入框** → 没有第一眼可见的「剧本输入」大框，导致没法输入剧本、后面 5 个逻辑环节（提示词生成/导演台分段/分段视频审核/返工/整片审核）无法测试。
2. **审核结果/生成内容不完善** → 审核尾部要显示「当前素材审核多少分」；素材库区域要显示审核评分/状态。
3. **项目管理与上下文缺失** → 要能选项目、自动扫描项目目录、选到项目自动加载上次保存的资产图/提示词/视频；输入新剧本可继续，避免换章节导致人物漂移/不一致。
4. **部分按钮重叠**。

## 二、用户采纳的点（照做）

| 采纳点 | 实现方式 |
|---|---|
| 自动生成区域**蒙版** | 素材槽/自动提示词/时间轴/导演台高级项盖**斜纹半透明蒙版**，蒙版上写「该内容将由程序根据剧本自动生成」 |
| 蒙版旁放**手动选择按钮** | 每个蒙版区右上角「手动选择/手动填写」按钮，点击解除该区域蒙版 |
| 提示词等所有自动内容都蒙版 | 提示词 JSON/分段提示词区同样蒙版；只有需要改的才可编辑 |
| **用户可修改项前置** | 顺序：① 剧本 → ② 项目 → ③ API Key/模型 → ④ 输出文件名/段数/分辨率，其余折叠/蒙版 |
| 其他隐藏项排后 | 长表单默认收起（高级区），排在可编辑项之后 |
| **项目选择/续写** | 顶部项目下拉 + 刷新/新建；扫描 `BETTERCOMFYUI_HOME/projects/`，选项目自动加载已有资产图/提示词/成片清单；新剧本继续复用项目素材库（防人物漂移） |
| 素材库显示**审核分数/状态** | 素材卡 + 审核汇总显示分数、LOCKED/BLOCKED/FALLBACK/CNT1 |
| **明显提示** | 状态灯 + 下一步按钮 + 蒙版文案（不是一行小字） |

## 三、用户未采纳/降级的点

| 原方案 | 处理 |
|---|---|
| 首启三步浮层引导（偏文字） | **降级为 P2**：改为内联可点的「状态灯+下一步」；只有用户主动点「?」才显示引导卡 |
| 纯文字长说明 | 不用；一律改成蒙版文案 + 按钮 + 红黄绿状态 |
| 参数三档全部展开 | 只保留「常用默认展开 / 高级折叠」，不搞三档复杂切换 |
| 错误列表弹窗 | 改为控件红点 + 顶部「N 处需修改」跳转（P1） |

## 四、实施与验收

- 实现：ui-agent（web/路由/展示）+ director-agent（节点审核数据/项目续写/字段合同）；Lead 集成部署 + 真机测试；
- 验收：
  1. 打开工作流首屏就能看到「① 粘贴剧本」大输入框（截图）；
  2. 自动区域有蒙版 + 手动按钮，点击可解除；
  3. 素材卡/审核汇总显示真实分数与状态（真机跑一次）；
  4. 项目下拉能列出已有项目并加载旧资产/提示词/成片清单；换项目/续写不丢素材库；
  5. 80% 缩放/窄窗口按钮无重叠；
  6. 旧工作流兼容、节点类型不变、DOM 不进执行入参。
