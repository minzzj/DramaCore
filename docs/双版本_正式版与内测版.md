# 双版本：正式版 vs 内测版

> 一个插件目录，两套工作流：打开哪套就是哪个版本。
> 正式版 = 稳定交付；内测版 = 更快 + 效果更好的公测链路。

## 版本一览

| 频道 | 版本 | 状态 | 下载 |
|---|---|---|---|
| 🟢 正式版（稳定） | `v0.2.0-internal` | 默认；昨晚测试通过 | [正式版 ZIP](https://github.com/minzzj/DramaCore/releases/download/v0.2.0-internal/DramaCore-v0.2.0-internal.zip) |
| 🟡 内测版（公测） | `v0.3.0-beta.1` | prerelease；可能不稳定 | [内测版 ZIP](https://github.com/minzzj/DramaCore/releases/download/v0.3.0-beta.1/DramaCore-v0.3.0-beta.1.zip) |

## 正式版（稳定）

- 定位：默认交付/出片；正式版 Release 已设为 latest；
- 工作流（`bettercomfyui_comfy/workflows/`）：
  - `【新版】剧核_单节点_剧本到成片_真实参数版_20261024.json`
  - `【新版】剧核_单节点_剧本到成片_快速4步版_20261024.json`
- 参数：r2v + 素材图审核 LOCK；真实参数版 1344×768 / 8 步；快速版 1152×640 / 4 步。

## 内测版（公测）

- 定位：验证更快 + 效果更好的新链路，**不要直接用于正式交付**；
- 工作流（`beta/workflows/`，安装内测包后菜单也会出现【内测版】）：
  | 文件 | 规格 | 适用 |
  |---|---|---|
  | `内测版_高质量_2x15s.json` | 2×15s ≈ 30s | 画质优先 |
  | `内测版_极速_2x10s.json` | 2×10s ≈ 20s | 速度优先 |
- 公共参数：t2v / 生成素材图=关 / 1376×768 / 8步 / 24fps / 转场=无 / 字幕=无 / 自动返工=关；
- 借鉴外部 H3 导演台高质量工作流的经验：纯 t2v、无素材图链、长段、单次封装。

## 安装与切换

1. 正式版：安装正式版 ZIP，打开根目录【新版】工作流；
2. 内测版：安装内测版 ZIP（可覆盖同一 `custom_nodes/bettercomfyui_comfy`），重启、Ctrl+F5，打开【内测版】工作流；
3. **切换 = 打开另一套工作流**，无需卸载/重装；
4. 版本标识：正式版 `__version__=0.2.0-internal`；内测版 `__version__=0.3.0-beta.1`，UI 徽章显示「内测 0.3.0-beta.1」。

## 回退（重要）

- 内测版报错/画质回退 → 重新打开正式版工作流；正式版文件始终保留；
- 内测版导致 ComfyUI 启动失败 → 移走/删除 `beta/` 目录，重启即回正式版；
- 不要把内测版设为默认交付；等 GPU 上 A/B 稳定后再并入正式版；
- 代码改动有 `.bak_r83_*` / `.bak_r84_*` 备份，编译/检查失败自动回滚。

## 核心差异

| 项 | 正式版 | 内测版 |
|---|---|---|
| 任务模式 | r2v + 素材图 LOCK | t2v 纯文生视频 |
| 素材图 | 开（SDXL） | 关（省素材链） |
| 段数/时长 | 1×5.167s（真实参数版） | 2×15s / 2×10s |
| 分辨率 | 1344×768 | 1376×768 |
| 转场/字幕 | AI自动 / 硬字幕 | 无 / 无（单次封装） |
| 自动返工 | 开 | 关（效率优先） |
| 状态 | 稳定交付 | 公测 |
