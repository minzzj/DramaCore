# 双版本：正式版 vs 内测版

剧核 DramaCore 现在分两个频道，同一个插件目录、同一套代码，靠**打开哪套工作流**区分行为。

## 正式版（稳定）
- 版本：`v0.2.0-internal`
- 定位：**昨晚测试通过的稳定链路**，默认交付/出片使用。
- 工作流：
  - `bettercomfyui_comfy/workflows/【新版】剧核_单节点_剧本到成片_真实参数版_20261024.json`
  - `bettercomfyui_comfy/workflows/【新版】剧核_单节点_剧本到成片_快速4步版_20261024.json`
- 下载：[正式版 ZIP](https://github.com/minzzj/DramaCore/releases/download/v0.2.0-internal/DramaCore-v0.2.0-internal.zip)

## 内测版（公测）
- 版本：`v0.3.0-beta.1`
- 定位：**更快 + 效果更好**的新链路；基于外部 H3 导演台高质量工作流的经验：纯 t2v、无素材图链、2×长段、无转场/硬字幕、单次封装。
- 工作流（在 `beta/workflows/`）：
  - `内测版_高质量_2x15s.json`：2×15s ≈ 30s，画质优先
  - `内测版_极速_2x10s.json`：2×10s ≈ 20s，速度优先
- 下载：[内测版 ZIP](https://github.com/minzzj/DramaCore/releases/download/v0.3.0-beta.1/DramaCore-v0.3.0-beta.1.zip)
- 风险：公测阶段，可能 OOM/接缝/人物一致性回退；不要直接用于正式交付。

## 怎么切换
1. 两个频道共用 `ComfyUI/custom_nodes/bettercomfyui_comfy`，**不用重复安装**；
2. 正式版 = 打开根目录两套【新版】工作流；
3. 内测版 = 打开 `beta/workflows/` 下内测版工作流；
4. 内测版报错/效果差 → 重新打开正式版工作流即可回退；正式版文件始终保留。

## 自动回退约定
- 内测版只作为独立文件/独立 ZIP，不覆盖正式版；
- 内测版报错：回到正式版工作流，保留报错日志；
- 代码侧改动都有 `.bak_r83_*` / `.bak_r84_*` 备份，编译/JS 检查失败会自动回滚；
- 等内测链路在 GPU 上稳定、A/B 通过后，再把参数并入正式版。

## 两个版本的差异（核心）
| 项 | 正式版 | 内测版 |
|---|---|---|
| 任务模式 | r2v + 素材图审核 LOCK | t2v 纯文生视频 |
| 素材图 | 开（SDXL） | 关（省素材链） |
| 段数/时长 | 1×5.167s（真实参数版） | 2×15s / 2×10s |
| 分辨率 | 1344×768 | 1376×768 |
| 转场/字幕 | AI自动 / 硬字幕 | 无 / 无（单次封装） |
| 自动返工 | 开 | 关（效率优先） |
| 定位 | 交付稳定 | 速度/画质试验 |
