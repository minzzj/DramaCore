# 使用指南：素材生成 · 素材审核 · 视频审核

> 对应逻辑图：`文档/BetterComfyUI_完整总流程图.dot`
> SG2 素材生成 → SG3 素材审核 → SG4 导演台 → SG5 视频段审核 → SG6 整片审核。
> 本文只讲**怎么用**；原理与证据见 `docs/ROUND27_素材与视频审核补齐报告.md`。

---

## 0. 完整链路现在长什么样

```
【SG1+SG2+SG4 一个大节点】                【SG3 素材审核】        【SG4 出片】            【SG5+SG6 视频审核】
剧本 → 一次API → E1–E5 提示词
     → 素材提示词自动登记素材库
     → 已LOCK素材挂每段 → 导演组  ──┐
                                   ├─ 素材生成(S3) → 入库 → 素材审核 → LOCK ─┐
                                   │   （图片/素材环节）                      │
                                   └──────────────────────────────────────→ 导演台（插模型）→ 成片
                                                                                    │
                                                                        视频审核(S4)：段级+边界+整片
```
* **一个大节点**（`BetterComfyUIEverything`）负责剧本→提示词→素材库→导演组（ROUND26）；
* **素材生成 + 素材入库 + 素材审核**（S3 工作流 / 3 个节点）负责图像环节；
* **视频审核**（S4 工作流 / 1 个节点）负责段级 R_seg + 边界 + 整片 R_full；
* 段级回灌审核还有一个既有入口：`BetterComfyUIFusionIngest`（导演台逐段产物回灌）。

## 1. 素材生成 + 素材入库 + 素材审核（S3）

### 1.1 打开哪个工作流

ComfyUI → 工作流 → **`S3_素材生成入库审核（GPU）`**（12 节点）。

### 1.2 每一步干什么

| 节点 | 你要做的 | 说明 |
|---|---|---|
| **素材生成·取任务** | 「项目」填项目显示名或 32 位 id | 自动从素材库取**下一个待生成素材**（大节点登记过、还没有版本的），输出提示词 + 生成参数 |
| **CheckpointLoaderSimple** | **选你自己的图像模型**（SDXL/Flux/…） | 本机没有图像权重，这一步到 GPU 机器才跑得动 |
| **CLIPTextEncode / 负向** | 一般不用改 | 正向自动接「提示词」；负向给了默认词 |
| **EmptyLatentImage / KSampler** | 需要时改尺寸/步数/采样器 | 可参考「素材生成·取任务」输出的「生成参数JSON」 |
| **素材入库** | 「项目」同上；素材ID 自动接 | 把生成图保存为**新版本**：算 SHA-256、状态 `PENDING_REVIEW`，绝不覆盖旧版本 |
| **素材审核** | 默认「模型审核（本地启发式）」+ asset_id/version 留空 | 自动审核刚入库的版本；通过 → 版本级 LOCK（`MODEL_PASS`）；未过 → `BLOCKED` 并累计 CNT1；到候选上限按最高分兜底（`FALLBACK_PASS`） |
| **3 个预览** | 看输出 | 进度（如 `0/7`）｜入库版本+指纹｜审核状态+评分+LOCK |

### 1.3 操作节奏

点一次「队列」= 生成一张图 → 入库一个版本 → 审核一次。
看「素材生成·取任务」的「进度」：`x/总数`；重复点队列直到进度满。
每个素材想要几张候选就多点几次（每次都是新版本 v2、v3…，旧版本与其审核记录都保留）。

### 1.4 只想手动审核（日常最常用）

不用跑 S3 也可以：单独拖出节点 **「素材审核」**（`BetterComfyUIAssetReview`）：

1. `project_id` 填项目 id；
2. `action` 选 **`列出待审版本`** → 点队列 → 在节点输出里看到所有待审的 `asset_id / version`；
3. 改成 **`人工通过`** 或 **`人工拒绝`**（`asset_id`/`version` 填上；留空=自动取第一个待审）；
4. 点队列。通过 → 版本级 LOCK（`HUMAN_PASS`）；拒绝 → `BLOCKED`，不会污染旧版本。
5. 其他动作：`模型审核（本地启发式）`、`人工超时→切模型（强制）`（演示 AUTO_SWITCHED，CNT1 从 0 起）、`查询审核状态`。

> 审核阈值：`config/default.yaml → asset_review.score_threshold`（默认 70）。
> `asset_review.model_candidate_limit`（默认 3）= CNT1 上限。

### 1.5 素材生成/审核相关输出在哪

| 内容 | 位置 |
|---|---|
| 素材版本文件 | `projects/<项目id>/assets/…`（只追加，不覆盖） |
| 素材索引/版本/审核状态 | `projects/<项目id>/meta.json` |
| 审计事件 | `projects/<项目id>/logs/events.jsonl` |
| CNT1 计数 | `projects/<项目id>/counters.json` |

## 2. 视频审核（S4：段级 R_seg + 边界 + 整片 R_full）

### 2.1 打开哪个工作流

ComfyUI → 工作流 → **`S4_视频审核（本机可跑）`**（5 节点；本机有 ffmpeg 就能跑）。

### 2.2 怎么填

| 参数 | 怎么填 |
|---|---|
| **项目** | 项目显示名或 id（要真实存在；审核记录会写到该项目下） |
| **视频文件路径** | 成片 mp4 的**绝对路径**（W0/W2 在 GPU 机器出片后，从 SaveVideo 输出目录拿）；本机测试可用任意 mp4 |
| **每段时长_秒** | 与导演台分段一致（默认 10 秒）。节点会按这个时长把成片切段做 R_seg |
| **审核范围** | 段级+整片（推荐）/ 仅段级 / 仅整片 |
| **评分来源** | 本地启发式（真实计算）/ 人工分数JSON（想自己给分时用） |
| **段阈值覆盖 / 整片阈值覆盖** | -1 = 用配置；想强制测试可填 0（必过）或 100（必不过） |
| **整片失败策略** | 按项目配置 / 阻止输出 / 降级输出（`FULL_REVIEW_DEGRADED`） |
| **边界相似度阈值** | 第 N 段尾帧 vs 第 N+1 段首帧的直方图相似度下限（默认 55） |

点队列，看 4 个预览：

1. **结论**：通过 / 需返工（可能带降级标记）
2. **段审核JSON**：每段的 R1a 四维分数、阈值、是否通过、CNT2/CNT3、兜底信息、边界验证
3. **整片审核JSON**：R1b 四维、最终分、阈值、是否通过、失败策略（block/degrade）
4. **审计报告**：范围/段数/需重生成段/降级标记/记录文件位置

### 2.3 结果怎么用

* 「需重生成段」非 `无` → 到 GPU 机器只重做这些段（导演台/一体化总控台），**新版本必须重跑 S4**
  （旧版本审核结论不适用，这是硬规则）。
* 计数在 `projects/<项目id>/counters.json`；历史在 `projects/<项目id>/review/video_reviews.json`。
* 第 N 段变化后，S4 会检查 N/N+1 边界；边界不过会把该段列入需重生成（级联验证）。

### 2.4 评分是什么

本地启发式 = 从**真实像素/帧**算出来的（非常量）：
* 段级 R1a：画面连贯（帧差）、无闪烁（帧差尖峰）、角色一致（首尾直方图相似）、动作合理（帧差离散度）；
* 整片 R1b：叙事流畅（镜头切分率）、音画同步（音轨与时长）、节奏合理（帧差稳定性）、无明显跳变（尖峰）。
它抓的是**机械问题**，判断不了剧情语义。要语义审核 → 替换评分模型（配置阈值仍生效）。

## 3. 段级回灌审核（既有入口，本轮修好）

`BetterComfyUIFusionIngest`（融合·回灌）用于**导演台逐段产物**：

* 输入：`project_id`、`segment_index`、`images`（该段帧）、`fps`；可选 `audio`；
* 行为：写段版本 + 内容指纹 + 审核材料 → **真实帧统计评分** → 段级审核 → CNT2/CNT3 记账；
* 输出：`audit_id`、`frame_count`、报告。

> 本轮修复：此前它用**常量 80 分**当评分（永远通过=假审核），现在改成真实帧统计；
> 拿不到帧就明确失败，不再假装通过。

## 4. 常见问题

| 问题 | 答案 |
|---|---|
| S3 点队列报错 / 生成不出图 | 需要用**你自己的图像模型**：在 CheckpointLoaderSimple 里选一个已安装的模型；本机没有图像权重就会失败（不是节点问题） |
| 素材审核说"没有待审版本" | 先用「一体化总控台」生成素材提示词（自动登记待生成素材），再到 S3 生成/入库 |
| 审核分数偏低 / 总不过 | 本地启发式看清晰度/构图；换分辨率更高、构图更好的图；或把阈值配置调低；要语义审核就换评分模型 |
| LOCK 后导演台用不上 | 导演台只挂 **已 LOCK** 素材；审核通过后重跑大节点/导演台即可 |
| 本机能不能跑 W0/W2 | **不能**（会加载 34GB 权重 → 死锁）。本机只跑 P1（看提示词）、W0L（占位）、S3（只看结构，无图像模型）、S4（视频审核，任意 mp4 可测） |
| 拼接/封装在哪 | 库里有 `pipeline.splice/encode`，`BetterComfyUIRun`/CLI 在跑；界面独立节点是下一步 |
