# 工作流说明（完整工作流）

工作流文件位于 `bettercomfyui_comfy/workflows/`，在 ComfyUI 里通过「打开/浏览」或拖入 JSON 加载。

## 推荐工作流

### 1. 【新版】剧核_单节点_剧本到成片_快速4步版_20261024.json
- 用途：快速测试/预览
- 默认参数：1152×640、4 步、`minimax_h3_ref2v_turbo_4step_v0.1_comfyui_bf16.safetensors`、参考最长边 512、段间连续=True
- 建议：每批段数=1；显存档位=低（最省）

### 2. 【新版】剧核_单节点_剧本到成片_真实参数版_20261024.json
- 用途：正式出片
- 默认参数：1344×768、8 步、`minimax_h3_ref2v_turbo_8step...` LoRA、参考最长边 512、段间连续=True
- 建议：显存 48G 实例；OOM 时自动降级（连续关闭/批 1/清理）

### 3. 00_【单节点】剧本→成片（无外部依赖）.json
- 单节点完整链路（素材→导演台→审核→剪片），参数可自行调整。

## 其它子流程
`W1/W2/W3/W4` 入门、`S1~S4` 素材/审核、`P1` 提示词、`00_【总流程】*` 分步流程；
适合调试单个阶段。

## 注意
- 工作流不含任何 API Key；
- 打开旧工作流若提示参数不一致，本版前端会自动修复；
- 系统提示词默认 `h3_v3_contract`（V3.0，唯一提示词）；
- **统一风格默认值是示例，请自行修改或替换**（见 `docs/自定义风格与系统提示词.md`）。
