# 测试机 / 生产机 环境预装清单（GPU 实机）

> 用途：SSH 拿到机器后**最短时间跑通**，避免现场装环境耗时。
> 目标机器：
> * 测试机：**RTX 4090 48GB（改装）**
> * 正式生产：**RTX 5090 32GB**（显存必须控制在 32GB 以下）
>
> 下面 Linux（云 GPU 常见）为主，Windows 差异单列。**版本必须按表装，尤其 5090 是 Blackwell（sm_120）。**

---

## 0. 一句话预装结论

| 组件 | 4090 测试机 | 5090 生产机 |
|---|---|---|
| NVIDIA 驱动 | ≥ 550.54（cu124）或 ≥ 570（cu128） | **≥ 570 / 推荐 580+** |
| CUDA Toolkit | 12.4 或 12.8 | **12.8+** |
| cuDNN | 9.x（对应 cu12） | **9.7+** |
| PyTorch | 2.5~2.8（cu124/cu128） | **2.7+（cu128）** |
| Python | 3.11 | 3.11 |
| ComfyUI | 0.41.0（与本机一致，或最新版） | 同左 |
| ffmpeg | ≥ 6（带 libx264 + aac） | 同左 |
| 内存 | ≥64GB | ≥64GB（推荐 96~128GB） |
| 磁盘 | ≥200GB NVMe | ≥200GB NVMe |
| 网络 | 需访问 api.deepseek.com（真实提示词） | 同左 |

> 5090 必须 PyTorch 2.7+ / CUDA 12.8：否则 sm_120 不被支持，会回退 CPU/极慢或报 no kernel image。

## 1. Linux（Ubuntu 22.04 / 24.04，云 GPU 推荐）

```bash
# 1) 驱动（机器通常已带；确认版本）
nvidia-smi                      # 看 Driver Version / CUDA Version / 显存
nvcc --version || true

# 2) CUDA Toolkit（若镜像未带；以 12.8 为例）
#    推荐直接用官方 runfile 或 conda 安装；镜像一般已含，优先用镜像自带

# 3) cuDNN 9.7+（对应 CUDA 12.x）
#    下载 cuDNN 9.7.x for CUDA 12 → 解压 → 拷贝头/库到 /usr/local/cuda，执行 ldconfig

# 4) Python 环境（推荐 conda/venv，Python 3.11）
conda create -n bcu python=3.11 -y && conda activate bcu
# 或: python3.11 -m venv .venv && source .venv/bin/activate

# 5) PyTorch（4090 测试机）
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
# 5090 生产机：同样 cu128，但必须确认 torch>=2.7 且 torch.cuda.get_device_capability() == (12, 0)
python -c "import torch;print(torch.__version__, torch.version.cuda, torch.cuda.is_available(), torch.cuda.get_device_capability())"

# 6) ComfyUI
git clone https://github.com/comfyanonymous/ComfyUI.git && cd ComfyUI
pip install -r requirements.txt
# 可选：pip install comfyui-frontend-package==1.55.17 comfyui-workflow-templates==0.11.86

# 7) ffmpeg
sudo apt-get update && sudo apt-get install -y ffmpeg
ffmpeg -version | head -1     # 需含 libx264 / aac

# 8) 本项目额外依赖（本插件用到）
pip install pyyaml pillow numpy imageio-ffmpeg
# 可选：pip install playwright && playwright install chromium   # 真浏览器验收需要
```

## 3. 模型文件放置（按 ComfyUI 目录）

| 文件 | 放到 | 体积 |
|---|---|---|
| `minimax_h3_ref2va_pruned_int8_convrot.safetensors` | `models/diffusion_models/` | 19.53GB |
| `minimax_h3_fl2va_pruned_int8_convrot.safetensors`（备用） | `models/diffusion_models/` | 19.53GB |
| `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors` | `models/text_encoders/` | 14.61GB |
| `minimax_h3_video_vae_fp16.safetensors` | `models/vae/` | 4.85GB |
| `minimax_h3_audio_vae_fp32.safetensors` | `models/vae/` | 0.56GB |
| `minimax_h3_fl2v_lightx2v_turbo_4step_v0.1_…bf16.safetensors` | `models/loras/` | 0.29GB |
| 图像模型（用户自己的 SDXL/Flux 等） | `models/checkpoints/` | 6~20GB |
| 导演台/巨人插件 | `custom_nodes/` | — |

合计约 **60~80GB**；建议磁盘预留 **≥200GB**（模型 + 成片 + 拼接临时段）。

**4090 特别注意（NVFP4 文本编码器）**：
- 4090 是 Ada，无 NVFP4 硬件。直接加载 nvfp4 文件可能报错，或被迫 dequant 成 BF16（32B≈64GB，爆显存）。
- 预装前请确认以下之一：
  a) 有 **FP8 版** qwen3vl-32b 文本编码器（≈32GB，分阶段可放进 48GB）；或
  b) 有 **AWQ/int4 且纯 int4 GEMM** 能跑的版本；或
  c) 机器 **内存 ≥64GB**，文本编码器放 CPU 跑（慢，但可用于流程验证）。
- 若三样都没有，测试机只能验证"结构/流程"，**不能验证真实出片效率与质量**，需要提前告知。

## 4. 本项目部署（拿到机器后）

```bash
# 把整个项目目录（含 bettercomfyui/、bettercomfyui_comfy/、comfyui 自定义节点、config、projects）
# 拷到机器上，例如 /data/BetterComfyUI
cd /data/BetterComfyUI
cp -r bettercomfyui_comfy/* ComfyUI/custom_nodes/bettercomfyui_comfy/   # 或直接软链
cp -r bettercomfyui ComfyUI/custom_nodes/bettercomfyui/                 # 编排包（导入用）
# 巨人：ComfyUI_MiniMaxH3_Director / Smart_Director / ChainDirector / Storyboard-LLM / DeepSeek connector
python -B scripts/sync_to_comfyui.py          # 若脚本按本机路径工作，机器上等价于上面两步
# 配置：config/user.yaml 填 DeepSeek Key、endpoint；config/default.yaml 保持默认
# 启动（32GB 生产机推荐参数）
COM: python main.py --listen 0.0.0.0 --port 8188 --reserve-vram 1.5
# 环境变量：PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True
```


## 6. 采集给 Lead 的实测数据（用于回填双卡报表）

```bash
# 显存采样（跑的时候另开终端）
nvidia-smi --query-gpu=timestamp,memory.used,memory.total,utilization.gpu --format=csv -l 2 > vram.log &
# 每段耗时：ComfyUI /history 的 execution 时间戳差；或外层计时
# 单段实测：3 段热身 + 10 段稳态，记 t_seg（秒/段）
# 质量：产物 mp4 用 ffprobe 查分辨率/fps/时长/码率/音轨
ffprobe -v error -show_entries format=duration,size,bit_rate -show_entries stream=codec_name,width,height,r_frame_rate,channels -of json final.mp4
```
