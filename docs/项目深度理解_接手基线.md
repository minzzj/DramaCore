## 3. 全局硬语义（改任何代码前先背下来）

来自方案第七部分（**冲突时以它为准**）+ `bettercomfyui/models/enums.py`（枚举唯一真源，343 行）。

1. **审核对象 = 素材条目 + 具体版本**。每版本有自己的指纹、审核记录、最终结论。
2. **LOCK = `LOCK_{素材全局ID}_{版本号}`**，只授权对应版本；来源三值 `HUMAN_PASS / MODEL_PASS / FALLBACK_PASS`；**新版本绝不继承旧 LOCK**。
3. **`FALLBACK` 不伪装成普通通过**：必须写入来源与评分；是否继续由项目兜底策略决定。
4. **CNT1 = 模型素材审核候选轮次**（人工次数不计、切模型时从 0 开始、版本递增不清零，默认≤3）。
5. **CNT2 = 当前问题段质量返工次数**；**CNT3 = 级联段重生成次数**；两者独立累计、不互相加、不因版本递增清零。
6. **技术失败（FAILED）≠ 质量不合格（BLOCKED）**：技术失败不占用候选/重做次数。
7. **H_arb**：人工与模型并发/超时切换后的迟到结果，按**同一后端时间戳**仲裁（人工更早→人工胜 + ABORT_SIGNAL；否则模型胜，人工只记日志）；**最终结论只提交一次**（`finalization_token` / `review_cycle_id`），未胜出结果不得更新素材库或启动下游。
8. **段级审核 R1a 与整片级 R1b 维度不同**；`R_full` 只在最终拼接后、`S_OUT` 前**执行一次**；`audit_scope ∈ {segment, full, both}`。
9. **新段版本必审**；旧版本审核结论失效；N1 新版本只做 R_seg + 相邻边界验证，**不触发 R_full**。
10. **级联必须终止**：只有依赖确实失效才继续标记后续段；`max_cascade_depth` 等上限必须生效，禁止无限循环。
11. **整片审核失败策略必须显式**：`block_output` 或 `degrade_output`（记录 `FULL_REVIEW_DEGRADED`），**不得隐式决定**。
12. **标识体系**：12 个审核状态码、22 条状态转移（`REVIEW_TRANSITIONS`）、ID 不含可变状态、原子写（tmp+`os.replace`）、文件锁贯穿整个 read-modify-write 周期、幂等键先 canonical_json 再 SHA-256、内容指纹 `sha256:{hex}` 核验。
13. **R1–R5 五条契约硬规则**（`docs/CONTRACTS.md`）：存在性只能程序判断 / 只追加不覆盖 / LOCK 绑三要素 / 计数器语义隔离 / 路径含 project_id。
14. **mock 与真实必须可区分且落盘**：`MovieMetadata.generation_provenance` 必填（含 is_mock/executor/reason/unverified）；空即拒写。

## 7. Bug 热点地图（按「概率 × 影响」排序，修 bug 从这里挑）

### A. 隔离 / 污染类（**P0，最伤用户信任**）

- **A1 打开网页会静默改写用户配置**（本次实测复现）：
  面板把 `BetterComfyUI.ApiBase` 注册为 ComfyUI 原生设置，其 `onChange` 会直接
  `POST /bettercomfyui/settings`（`web/js/bettercomfyui_panel.js:515-523`）。
  原生设置里持久化着 `"BetterComfyUI.ApiBase": "https://api.deepseek.com/v1"`
  （`.comfyui/user/default/comfy.settings.json:2`），于是**浏览器一打开页面**，设置恢复触发 onChange，
  `config/user.yaml` 的 `prompt.endpoint` 被改成 `/v1`（本次实测：19:35:24 被改写，已还原），
  同时巨人 `settings.json` 的 `base_url` 也被同步改写。
  → 修法方向：onChange 只在**用户显式编辑**时保存（区分程序化恢复），或校验「值确实变了且来源是用户」。
- **A2 验收测试写真实 `config/user.yaml`**：`tests/verify/test_acceptance_30_*.py:48` 直接
  `USER_CONFIG = REPO_ROOT/"config"/"user.yaml"`，测试用的假密钥

  模块级 backup/restore 夹具存在，但被 A1 的「打开页面自动保存」绕过。
  → 修法：用临时仓库（`tmp_path` 覆盖 `cfg.global_.project_root` + `repo_root`），不碰真实配置。
- **A3 `.comfyui/custom_nodes/projects/` 杂散目录**：无 `__init__.py`，ComfyUI 启动报错警告；
  内含嵌套 `projects/projects/` + 5 个项目目录。来源疑为历史上 `REPO_ROOT` 解析错误把项目根写进
  `custom_nodes`（ROUND22 修过一次同类问题：写到了 `custom_nodes/config/user.yaml`）。
