## 五、效率推算（回填公式）

```
4090 总时长 ≈ N × t_seg(4090) + 加载开销

有效加速比 S = t_seg(4090) / t_seg(5090)   # 实测后回填理论区间 1.4~1.7
1 小时片 N ≈ 360 段
```
