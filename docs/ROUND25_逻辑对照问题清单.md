## 四、修复方案（本轮实施）

| 编号 | 修复 | 对应问题 |
|---|---|---|
| F1 | 新增编排层 `bettercomfyui/prompt/script_build.py`：**一次** `gateway.complete` → `parse_script_output(auto)`（JSON/预设分隔符）→ `canonicalize_script` → `validate_script` → 按 CHARACTER/SCENE/PROP/SHOT 拆分 → 输出标准 JSON + `---` 视频提示词 + 统计（调用次数/耗时/模型）；错误带原始响应片段，绝不静默 | 1.1/3-E1~E4/基准① |
| F2 | 新增界面节点 `BetterComfyUIScriptPrompts`（剧本→全量提示词）：8 个输出——角色图提示词/场景图提示词/物品图提示词/分镜图提示词（JSON）、视频提示词（`---` 文本）、视频提示词JSON、全量JSON、摘要；接 Settings 的 key/model/base；无 key 时明确报错或显式占位 | 1.4/2.2/基准①② |
| F3 | 新增工作流 `P1_剧本→全量提示词（本机可跑）`：只走 API、零权重、**每个输出都接 PreviewAny**（结果可见）；重建 `W0`（真实链路 + 全输出可视化）；重建 `W0L`（占位演示）；重建 `W2`（类型/密钥/模型名修正） | 2.1/2.3/1.6/1.7 |
| F4 | 面板原生设置 `onChange` 加「仅在真实用户交互后保存」的保护，杜绝打开页面静默改写配置 | 1.3 |
| F5 | 验收 30 补齐三处配置文件的备份/恢复（含原生设置），杜绝假密钥残留 | 1.2 |
| F6 | 清空三处测试假密钥（不伪造"已配置"状态），由用户重新填真实密钥 | 1.1 |
| F7 | 新增验收 31：单次调用（计数断言）/分类拆分/标准 JSON/预设分隔符解析/错误可读/占位模式/工作流拓扑与可视化 | 全部 |

## 五、验收口径（本轮结束时给出）

1. 双解释器 `pytest tests/verify -q` 均 EXIT=0 且 FAIL=0；
2. 真实 ComfyUI `/object_info` 校验新工作流可加载、连线类型合法；
3. 真浏览器（系统 Edge）打开 P1、点队列、`/history` 中能看到 8 个输出且分类正确；
4. 用**本地 mock OpenAI 兼容服务**（不计费、不泄密）跑真实链路：断言 **API 调用次数=1**、返回被拆分并填到对应输出、摘要显示"一次调用/模型/耗时"；
5. 全程不加载任何 H3 权重（红线）。

> 不在本轮范围：真实视频出片（环境墙）、真实 DeepSeek 密钥调用（用户填入前无法验证，将如实标注"未验证"）、
> `BetterComfyUIEverything` 仍保留自写简化 prompt（列为后续统一项，避免本轮范围失控）。
