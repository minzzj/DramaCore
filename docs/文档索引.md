## 工作流在 ComfyUI 哪里

ComfyUI 页面 → 左侧「工作流」菜单：

- 正式版：`【新版】…快速4步版` / `…真实参数版`；
- 内测版（装内测包后）：`【内测版】…高质量_2x15s` / `…极速_2x10s`；
- 看不到：Ctrl+F5，确认打开的是 `http://127.0.0.1:8188`（或你的远程 IP:端口）。
