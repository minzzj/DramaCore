## 四、常用命令速查

```powershell
cd '[PROJECT-ROOT]'
python -B scripts/verify_install.py                 # 安装/节点/工作流检查
python -B -m pytest tests/verify -q                 # 三态验收（系统 python）
& .comfyenv\Scripts\python.exe -B -m pytest tests/verify -q   # 三态验收（ComfyUI 环境）
python -B -m pytest tests/ -q                       # 全量测试
python -B scripts/browser_screenshots.py            # 拍三套总流程界面截图
python -B scripts/make_usage_diagrams.py            # 生成流程图
python -B scripts/staged_run.py --dry-run           # 32G 分两段拆分结构验证
python -B scripts/quality_audit.py --video FINAL.mp4  # 成片质检（剪辑/完整/质量/占位）
```

## 五、三套总流程工作流在哪

ComfyUI 页面 → 左侧「工作流」菜单 → 找 `00_【总流程】…`：
- `00_【总流程】剧本→全部内容（本机可跑）`（不需要 GPU）
- `00_【总流程】段视频→剪好成片（本机可跑）`（不需要 GPU）
- `00_【总流程】剧本→成片（GPU）`（需要 GPU + 模型）

看不到时：**Ctrl+F5 刷新**页面，并确认连的是 `http://127.0.0.1:8188`。
