## 第一部分：你要的最终目标（愿景）

来源：`文档/BetterComfyUI完整方案.docx` 第一部分「愿景清单」。

### 1. 你要的不是一个更好的节点

> 当前开源 AI 生成行业，ComfyUI 占据了主体地位……但我越用越清楚地感受到它的根本性局限：
> 节点与外部系统级 AI 之间是割裂的，自动化与调度能力是薄弱的，它更像一个强大的手工工作台，
> 而不是一条真正能跑起来的自动化生产线。
>
> 这就是我的核心愿望。**不是做一个更好的节点，不是做一个更漂亮的界面，
> 而是做一套真正从剧本到成片的自动化系统。**
> 它应该**以成熟节点相互拼接为主，不全部自研**；它应该低风险、快落地、可开源；
> 它应该让每一个开源用户……**拿到之后能直接跑起来**，而不是面对一堆需要自己填的坑。

### 2. 三条路线，你选了第二条

| 路线 | 内容 | 你的选择 |
|---|---|---|
| 第一条 | 外置小资源包 + 外部程序转接（代码量最小，自由度最大） | |
| **第二条** | **插件或节点包集合。基于成熟导演节点、性能优化节点，制作集合包，互相连接，仅修改少量代码即可实现真正自动化。站在巨人肩膀上，开发风险最低，开源后最容易获得反响。** | ✅ **选它** |
| 第三条 | 真正的 Better ComfyUI（体验最好、架构最干净，但风险最高） | |

### 3. 你想要的完整流程

> 我给 DeepSeek 一段剧本，它自动拆解人物……输出人物图、角色图、场景图、物品图、分镜图的提示词，
> 以及最终视频生成提示词……提示词和素材进入素材库。
> 素材库是核心参考源……素材审核可以选择人工审核或模型审核……
> 人工超时后自动切换模型模式……
> 人工审核模式下可持续重试；模型模式下 CNT1 最多统计三轮模型审核候选，
> 仍不合格时选择候选最高分版本并记录 FALLBACK_PASS。

### 4. 你对连贯性的"执念"（原文强调）

> 我极其坚持的原则：**连贯性主来源不能是前一帧，必须是素材库参考图。**
> 人物、服装、场景、物品不一定出现在最后几帧。只靠前一帧，角色就会丢。
> 素材库参考图才是身份、造型、场景、物品一致性的核心。
> 尾部 22 帧只作动作、镜头、光线、节奏的辅助连续。
> 人物不在最后几帧时，必须由素材库角色图锁定身份，禁止仅用前一帧替代。

### 5. 一次性交付

> **导演台支持一次性直接输出约一小时的完整内容。我不需要逐段查看，逐段查看不是它的本意。**
> 它应该像一个真正的导演，自己知道怎么分段、怎么衔接、怎么保持连贯，
> 最后把一整部片子交到我面前。

### 6. 其他硬要求

- **显存在任何情况下都要节省**（剪枝模型、分段采样、潜变量轻量化、FP8、tiled VAE、tiled DiT、unload DiT）
- **全部本地完成**，不依赖外部 API 做审核，不需要云端调度、多用户、商业化
- **增量素材更新必须由程序做确定性注入，不能让 AI 判断**（DeepSeek 种子不固定，AI 判断会误判）
- **项目管理**：每个项目自己的素材库/章节/进度/成片，互不干扰，项目内素材累积复用
- **开源用户都是开发者**，手动操作和自动切换**只在日志记录**即可
- **手动添加的素材不审核，直接进素材库**
- **公共素材库和单独素材库不会冲突**
- 第一阶段只跑通主流程；第二阶段（保留接入点）做自动获取剧本、自动发布

## 第三部分：核心逻辑图要点（`文档/流程图-总.txt`）

你说的"整篇文章的核心"。以下是必须遵守的节点原文。

### 导演台与连贯性（图一 SG4 + 图二）

```
JP4["尾部帧数默认22可调"]
O1["自动取尾部22帧或前一帧无需手动切换"]
O2["主连贯性使用素材库参考图采用参考模式"]
O3["参考模式均可由节点自动处理"]
P1["人物不在尾部22帧时由素材库锁定"]

Q_OUT["一次性输出约一小时整片"]
```

→ **两套机制叠加**：尾部 22 帧（风格/动作/镜头，导演台原生自动）+ 素材库参考图（身份）。

### 素材复用（图二，关键）

```
subgraph 素材复用["素材复用：所有段都用这一套"]
    C_LOCK -->|"@引用"| SEG1
    C_LOCK -->|"@引用"| SEG5
    C_LOCK -->|"@引用"| SEG9
    C_LOCK -->|"下一部剧本复用"| NEXT
```

→ **同一套 LOCK 素材被所有段引用**。所以是"全量挂每一段"，不是按段挑选。

### 素材库结构（SG2）

```
G1["目录结构角色场景物品分镜四类分目录"]
G2["命名规则类型_序号_名称"]
G4["数量上限每类默认最多9张可调"]
G5["素材优先级角色>场景>物品>分镜"]
F["特殊分隔符自动分段"]
XF["@素材类型_序号_名称"]
```

### 审核与计数（SG3 / SG5）

- `SG3 素材审核（视频生成前只审一次）`；`LOCK["素材锁定冻结只此一次"]`
- 人工审核无限重试；模型审核最多 3 次取最高分；无人响应 10 分钟超时切模型
- `CNT1` 素材模型审核轮次；`CNT2` 段质量重做；`CNT3` 级联重做
- 技术失败（API/节点/超时/文件损坏）**不消耗** CNT2/CNT3
- 三次仍不合格 → 取最高分 + 记 `FALLBACK_PASS`

### 段级返工（SG5）

```
T["定位不合格段"] --> U["只重生成该段素材不动不重审"]
V["以该段素材首尾帧作参考"] --> W["第N+1段使用第N段首尾帧"]
X["提示词自动加相关提示词和@素材"]
```

### 导演台参数（JP1–JP7）

默认分段时长 **10 秒**（可调 5/10/15）；分辨率 **1080P**（720P/4K）；
帧率 **24fps**（30/60）；**尾部帧数默认 22 可调**；首尾帧默认第一帧和最后一帧；
显存档位自动检测；剪枝模型默认开启。

```

文本编码器           14.61 GB
最少需要             34.14 GB（仅权重）
本机物理内存         15.75 GB      ← 差约 18 GB
```

| 资源 | 换机要求 | 依据 |
|---|---|---|
| 显存 | **≥ 24 GB** | 实测峰值 22,016 MiB |
| 系统内存 | **≥ 64 GB** | 权重必须同时驻留 |
