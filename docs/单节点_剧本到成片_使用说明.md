# 单节点：剧本 → 成片（无外部自定义节点依赖）

> 文件：`bettercomfyui_comfy/one_stop_node.py`（节点类 `BetterComfyUIOneStop`）
> 工作流：`00_【单节点】剧本→成片（无外部依赖）.json`；远端 UI 菜单名 `【剧核】单节点_剧本到成片`

## 一、这是什么

用户要的「一个超长大节点」第一版：**工作流里只有一个节点**。

- 输入：一段剧本 + 模型文件名（UNET/CLIP/视频VAE/音频VAE/LoRA）+ 出片参数；
- 节点内部完成：
  1. 剧本 → **一次 API**（或占位）→ E1–E5 全量提示词 → 素材库登记（复用本包 `BetterComfyUIEverything`）；
  2. 视频提示词 → 导演台 r2v 组（`fusion.make_r2v_group`）；
  3. **节点内部加载模型**（ComfyUI 自带 loader，按各版本 INPUT_TYPES 自动适配参数）；
  4. 调用**已复制进本包**的导演台核心（`vendor/h3_director/`，MIT LICENSE 保留）真实出片（含音频）；
  5. 编码成 mp4 → 完整性/质量审核 → 导出到项目 output 与 `ComfyUI/output/剧核成片/`（网页可播放整片）。
- **不依赖外部自定义节点**：MiniMaxH3Director 等源码已在 `bettercomfyui_comfy/vendor/h3_director/`，
  用户不需要另装导演台/Storyboard/DeepSeek 连接器。

## 二、怎么用（远端 4090 机器）

1. 打开 ComfyUI（`http://your-gpu-host:8188`），刷新页面；
2. 工作流菜单选 **`【剧核】单节点_剧本到成片`**（只有一个节点）；
3. 节点上填：
   - **剧本**：粘贴一整段剧本（多章节也行）；
   - **api_key**：填你的 DeepSeek Key（或留空，服务器配置里有就用配置）；
   - 模型文件名：默认已填远端可用文件（UNET/CLIP/视频VAE/音频VAE/LoRA turbo）；
   - 想先看结构不调 API：把 **使用占位结果** 勾上（此时提示词是占位，但出片是真的）；
4. 点运行；完成后：
   - 节点输出「成片路径 / 审核报告 / 提示词JSON / 审计报告」；
   - 节点预览区/ComfyUI 输出目录 `output/剧核成片/` 里是**整片 mp4**，网页可直接播放。

## 三、参数说明（关键项）

| 参数 | 默认 | 说明 |
|---|---|---|
| 段数 | 1 | 本次生成几段（每段单独采样，段间自动拼接） |
| 每段时长_秒 | 5.167 | H3 turbo 单段实测口径（124 帧 @24fps） |
| 宽度×高度 | 864×480 | 480p 最快；高清建议 864×480 生成后超分（见 ROUND39） |
| 步数 | 6 | 配合 turbo LoRA；不接 LoRA 时需 25+ |
| 采样器/调度器 | euler/simple | 与 turbo LoRA 匹配 |
| 使用占位结果 | False | True = 不调用 API（0 次），仅测试结构 |
| 出片 | True | 关掉则只产出提示词/素材登记（不加载模型，调试用） |
| 审核阈值 | 70 | 本地启发式质量均分阈值（低于则“不通过”，如实报告） |

## 四、当前版本边界（诚实）

- **素材图生成暂未纳入本节点**（v0.1）：本次只做“提示词→素材登记”，不生成参考图；
  素材图生成/审核链路仍可用之前的 `S3_素材生成_4090适配版` 工作流（已真机验证）。
- 审核为**本地启发式**（真实帧统计，非语义模型），结果会写审核 JSON，不冒充语义审核。
- 高分辨率：本节点默认 480p 出片（快）；1080p 建议走「480p 生成 + 模型超分」路线（ROUND39 实测）。
- 显存：节点内部按顺序加载模型；48G 实测可用。32G（5090 生产）需按 ROUND39 的分阶段/降分辨率策略实测。

## 五、验收记录

见 `docs/ROUND41_单节点首版真机验证.md`：4090 真机 3 次运行，最终 **119.20s（含加载）/ 出片 93.8s**，
124 帧/864×480/5.167s/含音频，审核通过；成片导出 `ComfyUI/output/剧核成片/` 网页可播放。
