## 6. 对「先配默认系统提示词再发布」的具体建议（本轮评估的关键发现）

### 6.1 结论（必须先看）
> **15:15 更新：本缺陷已修复并验证**——单节点新增 4 个「跟随面板配置」参数并透传（`one_stop_node.py:528-536`、`:633-636`、`:678-715`），面板 `strict_json` 在真机 run07 审计中生效（「系统模板=严格 JSON（面板默认=是）」）。

**（14:05 原始分析）当时版本在面板里配「默认系统提示词」，对单节点真实 API 路径不生效**——配置会被内置预置覆盖。直接按此计划发布，用户看到的将不是用户配置的提示词。

静态调用链证据：
1. 面板保存：`routes.py:686-692` 把面板「默认系统提示词」写入 `config/user.yaml` 的 `prompt.system_prompt_template`（面板说明 `docs/剧核_DramaCore_面板配置说明.md:32`）。

4. 真实 API 分支无条件覆盖：`cfg.prompt.system_prompt_template = custom or template_key`（`everything_node.py:528-530`）→ 结果恒为内置 `default` 预置，**配置值被丢弃**。输出语言（`:531`）、分镜粒度（`:532`）同样被默认值覆盖（面板保存了但无效）。
5. 组合之后：`inject.resolve_system_prompt()` 收到 `"default"` → 返回内置角色块（`bettercomfyui/prompt/inject.py:46-49`、`:198-214`）。

> 说明：这是**静态代码证据链**，方向确定；14:05 时因无用户 Key 未做运行时验证——**16:20 已用真实 Key 完成该验证**：审计「系统模板=严格 JSON（面板默认=是）」+ 真实提示词 JSON 产出，P0-2 复验通过。

### 6.2 建议做法（按推荐顺序）
