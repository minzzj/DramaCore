# ROUND56 需求落地记录（2026-10-19 夜间）

> 用户需求：① 转场由程序自动决定（默认自动、逐处可见）；② 多段剧本/多提示词要「添加一段」按钮，支持任意多段；③ 默认配置/高级参数配置好且可见（高级内容加蒙版防小白误调）；④ H3 手册不要只追加要点，要真正填进系统提示词；⑤ 提示词要看得见（系统/逐段/素材）。

## 一、已实现

### 1. 多段剧本动态列表（R2）
- 新节点参数 `多段剧本列表JSON`（字符串数组；隐藏原生控件，由 UI 管理）；
- UI ① 剧本区：「多段剧本」开关 → 动态列表：**＋ 添加一段 / 删除 / 上移 / 下移 / 清空**，每段独立 textarea；
- 实时显示「N 段 · 预计 N 次 API（每段 1 次）」；
- 后端 `run()` 优先读 JSON 列表（每项 = 一章/一段剧本），为空时兼容旧「多段剧本 + 分隔符」文本；
- 段数上限 64（超出截断并告警）；旧版批量文本仍兼容。

### 2. 转场自动（R1）
- 节点 `转场` 默认 = **「AI自动（按剧情）」**（无需手动选）；
- 运行前自动调用规则引擎 `transition_planner.decide_transitions()`：pin 连续段强制轻转场/硬切、场景切换→叠化、时间跳跃→黑场、边界高相似→硬切；
- 决策写入报告 `transition_decision`（逐接缝类型/时长/原因/硬切），UI 审核汇总区新增「转场决策」卡片逐条显示；
- 仍保留手动指定转场（可选覆盖）。

### 3. 默认配置 / 高级蒙版（R3）
- 节点默认值：转场自动、字幕默认「硬字幕（程序对齐）」、系统提示词默认「H3 手册（完整，推荐）」、片头片尾无、tiled 0/重叠 64、素材 12、CNT2/3=3、每段 10s/1920×1088、审核阈值 70；
- 新工作流 119 values（按加载时真实 widget 顺序生成 + `tests/test_round55_workflow_alignment.py` 守卫）；
- 高级内容全部放入 `maskedSection`/`collapsible` 蒙版区（提示词编辑、生成/采样、增强、高级表单）；新增提示词面板需先点「✋ 手动编辑」才能改，避免小白误调。

### 4. H3 手册全文进入系统提示词（R4）
- 新增 `bettercomfyui/prompt/h3_handbook.py` + `bettercomfyui/prompt/data/h3_handbook_full.txt`（手册全文 **41966 字**）；
- 新增系统提示词预设：`H3 手册（完整，推荐）`（全文 42263 字）与 `H3 手册（精简）`（核心章节约 6664 字）；
- `everything_node` 命中手册预设时**直接把全文作为系统提示词**（不再只追加 2493 字要点），并附加禁字幕系统规则；
- 节点 `系统提示词选择` 默认 = H3 手册完整；面板仍可自定义覆盖。

### 5. 提示词可见（R5）
- 新增 `GET /bettercomfyui/prompt/handbook?mode=full|core` 路由返回手册全文/精简；
- UI 新增「⑭ 提示词（系统 / 分镜 / 素材）」蒙版区：
  - 默认展示当前生效系统提示词全文（面板已配置则显示面板配置，否则显示 H3 手册全文）；
  - 「手动编辑」解锁 → 可编辑 →「保存为面板默认」（写 `config/user.yaml`）；
  - 「加载 H3 手册全文 / 精简版」「复制」；
  - 运行后自动回填每段实际视频提示词（来自报告 `video_prompts`）供核对。

### 6. 硬字幕文本来源（补充修正）
- 字幕默认硬字幕；文本优先级：`字幕台词` → 剧本引号台词程序化提取（「」/“”/""）→ 视频提示词（并明确告警）；
- 时间轴仍由 `hard_subtitles.py` 程序帧网格生成，不靠模型/ASR，避免漂移。

## 七、用户反馈后的修复（22:30–22:50）

用户反馈：「添加一段按钮没有用」「默认配置没配置好」「有些高级参数没蒙上」。

### 修复 1：添加一段按钮（真 bug）
- 原因：`syncMultiChapters` 过滤空段 → 每次点击只保留 1 行，看起来"没用"；
- 修复：保留空段、点击后强制勾选多段开关并展开/滚动到列表；计数改为「已添加 N 段 · 有效 M 段 · 预计 M 次 API」；
- 实测：连点 2 次 → 3 个编辑框（1 初始 + 2 新增）。

### 修复 2：默认配置补全并可见
- 补全默认：片头文字=「剧核 DramaCore」、片尾文字=「剧终」、片尾演职员=「剧核 DramaCore 出品」、输出语言=中文、分镜粒度=按镜头、统一风格=电影感/真实自然/冷蓝电影光/低饱和/音画同步；配合已有转场=AI自动、字幕=硬字幕、系统提示词=H3 手册完整、素材12、CNT2/3=3、10s/1920×1088、审核70、tiled=0/重叠64；
- 新增**可见只读**「默认配置已设置（查看）」面板，列出关键默认值；
- 工作流重生成（119 values）并经 `test_round55_workflow_alignment.py` 逐项校验。

### 修复 3：高级参数蒙版补全
- ⑫ 片头片尾 / 素材版本回滚 / 字幕台词 全部包进蒙版（需点「✋ 手动选择/手动填写」才可改）；
- ⑭ 提示词面板：查看可见，编辑需「✋ 手动编辑」；
