## 0. 准备条件

| 项目 | 要求 |
|---|---|
| ComfyUI | ≥ 0.30（开发验证 0.41；目标机 0.33 可跑） |
| GPU | 真实出片建议 24GB 显存以上（H3 48G 更稳）；CPU 只能编排/占位 |
| 磁盘 | ≥ 150GB 空闲（H3 文本编码器 34GB 级 + 扩散权重 + VAE） |
| Python | 3.9+（推荐直接用 ComfyUI 自带 venv/便携版） |
| Git | 可选；没有 Git 可下载 ZIP |
| 模型权重 | **不在仓库**，需按许可自行获取（见第 4 节） |
| LLM API | DeepSeek 或兼容接口的 API Key（用于一次 API 拆剧本） |

## 1. 获取代码

```bash
git clone https://github.com/minzzj/DramaCore.git
cd DramaCore
```

不想装 Git：下载 <https://github.com/minzzj/DramaCore/archive/refs/heads/main.zip> 解压。
下文用 `<DramaCore>` 表示仓库根目录。

## 2. 一键安装（推荐）

安装器会：检测 GPU/后端/显存 → 安装 ComfyUI 依赖 → 放插件与编排包 → 生成启动器。
默认 dry-run 不写文件；确认后加 `-Yes` / `--yes`。**不会下载模型**。

### Windows

```powershell
cd <DramaCore>
powershell -ExecutionPolicy Bypass -File .\install\install_windows.ps1 `
  -Mode attach -ComfyUI "D:\ComfyUI" -DryRun
powershell -ExecutionPolicy Bypass -File .\install\install_windows.ps1 `
  -Mode attach -ComfyUI "D:\ComfyUI" -Yes
```

### Linux

```bash
cd <DramaCore>
chmod +x install/install_linux.sh
./install/install_linux.sh --mode attach --comfyui /opt/ComfyUI --dry-run
./install/install_linux.sh --mode attach --comfyui /opt/ComfyUI --yes
```

### macOS

```bash
cd <DramaCore>
chmod +x install/install_macos.sh
./install/install_macos.sh --mode attach --comfyui "$HOME/ComfyUI" --dry-run
./install/install_macos.sh --mode attach --comfyui "$HOME/ComfyUI" --yes
```

### 还没有 ComfyUI？

```powershell
powershell -ExecutionPolicy Bypass -File .\install\install_windows.ps1 -Mode bootstrap -ComfyUI "D:\ComfyUI" -Backend cuda -Yes
```

```bash
./install/install_linux.sh --mode bootstrap --comfyui "$HOME/ComfyUI" --backend cuda --yes
```

安装成功后会出现启动器（Windows `start_dramacore.bat` / Linux `start_dramacore.sh`）。
**以后用启动器启动**（自动设置 `BETTERCOMFYUI_HOME`），不要直接跑原版 `main.py`。

## 3. 手动安装

1. 把 `<DramaCore>/bettercomfyui_comfy` 放到 `<ComfyUI>/custom_nodes/bettercomfyui_comfy`（目录名必须一致）；
2. `<DramaCore>/bettercomfyui` 留在仓库；启动时设 `BETTERCOMFYUI_HOME=<DramaCore 绝对路径>`；
3. 用 ComfyUI 自带 Python 安装依赖：

```bash
<ComfyUI>/python -m pip install -r <DramaCore>/requirements.txt
```

4. 启动：

```bash
set BETTERCOMFYUI_HOME=D:\DramaCore
python main.py
```

## 4. 模型文件（必须自己准备）

> ⚠️ 仓库不含任何模型权重。文件名必须完全一致，否则工作流显示「缺失模型」。

| 放置目录 | 文件名 | 用途 |
|---|---|---|
| `ComfyUI/models/diffusion_models/` | `minimax_h3_ref2va_pruned_int8_convrot.safetensors` | H3 主扩散模型 |
| `ComfyUI/models/text_encoders/` | `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors` | H3 文本编码器（34GB 级） |
| `ComfyUI/models/vae/minimax/` | `minimax_h3_video_vae_fp16.safetensors` | 视频 VAE |
| `ComfyUI/models/vae/minimax/` | `minimax_h3_audio_vae_fp32.safetensors` | 音频 VAE |
| `ComfyUI/models/loras/` | `minimax_h3_ref2v_turbo_8step_v1.0_768p_comfyui_bf16.safetensors` | 真实参数版 LoRA（8 步） |
| `ComfyUI/models/loras/` | `minimax_h3_ref2v_turbo_4step_v0.1_comfyui_bf16.safetensors` | 快速 4 步版 LoRA |
| `ComfyUI/models/checkpoints/` | `RealVisXL_V5.0_fp16.safetensors` | 素材图生成（可暂不装） |

模型来源请走官方/授权渠道，遵守各自许可；仓库只提供工作流，不代下载。

## 5. 配置 API Key

```bash
cp config/user.yaml.example config/user.yaml
```

```yaml
prompt:
  endpoint: https://api.deepseek.com
  model_name: deepseek-chat
  api_key: '你的 Key'        # 不要提交
```

也可以不改文件：启动后在 ComfyUI 右侧「剧核」面板填写 Key。
`config/user.yaml` 已被 `.gitignore` 排除；**禁止把真实 Key 写进工作流/截图/Issue**。

默认系统提示词：`h3_v3_contract`（V3.0 契约对齐，37,457 字）。
默认统一风格只是示例，请按项目修改/替换。

## 6. 启动并跑第一个片子

1. 运行启动器（或设置 `BETTERCOMFYUI_HOME` 后 `python main.py`）；
2. 打开 `http://127.0.0.1:8188`，按 **Ctrl+F5**；
3. 加载工作流：
   - 测试：`bettercomfyui_comfy/workflows/【新版】剧核_单节点_剧本到成片_快速4步版_20261024.json`
   - 正式：`…真实参数版_20261024.json`
4. 节点首屏粘贴剧本 → 选项目 → 运行；
5. 成片输出在 `ComfyUI/output/剧核成片/`（同时写项目目录）。

## 7. 内测版（可选）

下载 [内测版 ZIP](https://github.com/minzzj/DramaCore/releases/download/v0.3.0-beta.1/DramaCore-v0.3.0-beta.1.zip)，解压覆盖同一插件目录，重启后打开【内测版】工作流。

- 内测版：纯 t2v、无素材图、2×15s/2×10s 长段、单次封装；
- **不稳定**；报错/效果差 → 重新打开正式版工作流即可；
- 启动失败 → 移走 `beta/` 目录重启即回正式版。
详见 [双版本说明](双版本_正式版与内测版.md) / [beta/README.md](../beta/README.md)。

## 8. 升级

```bash
cd <DramaCore>
git pull
```

重新运行安装器（`-Yes` / `--yes`）或覆盖插件目录 → 重启 → Ctrl+F5 → 重开【新版】工作流。
`config/user.yaml` 不会被覆盖。

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| 提示「编排包不可用」 | 启动时没设 `BETTERCOMFYUI_HOME`；用 `start_dramacore.bat/.sh` 启动 |
| 工作流显示「缺失模型」 | 对照第 4 节文件名/目录，逐字一致 |
| 「参数与插件节点不一致」 | Ctrl+F5 强刷并重开【新版】工作流 |
| API 401 | 检查 `config/user.yaml` 或面板 Key |
| 显存不足 OOM | 降分辨率/参考图、每批段数=1、显存档位=低；48G 更稳 |
| 远程面板写操作 403 | 用 `IP:端口` 访问；域名访问需设 `BETTERCOMFYUI_ALLOW_REMOTE_PANEL=1` |
| 端口被占用 | 关掉其它 ComfyUI 进程，或加 `--port 8189` |
