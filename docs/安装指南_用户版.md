# 安装指南（用户版）

> 目标：从零开始，在 **已有 ComfyUI** 上装好剧核 DramaCore，并成功加载【新版】工作流。
> 仓库地址：https://github.com/minzzj/DramaCore （Public · 版本 v0.2.0-internal）

---

## 0. 先确认你有哪些东西

| 项目 | 要求 |
|---|---|
| ComfyUI | ≥ 0.30（开发验证 0.41；目标机 0.33 也能跑） |
| GPU | 真实出片建议 **24GB 显存以上**（H3 48G 实例最稳）；CPU 只能编辑/占位 |
| 磁盘 | ≥ 150GB 空闲（H3 文本编码器 34GB 级 + 扩散权重 + VAE） |
| Python | 3.9+（推荐直接用 ComfyUI 自带的 venv/便携版 Python） |
| Git | 可选；没有 git 也可以下载 ZIP |
| 模型权重 | **不在本仓库**，需要自己按许可获取（见第 4 节） |
| LLM API | DeepSeek（或兼容接口）的 API Key，用于「一次 API」拆剧本 |

## 1. 获取代码

### 方式 A：git clone（推荐，方便升级）

```bash
git clone https://github.com/minzzj/DramaCore.git
cd DramaCore
```

Windows / Linux / macOS 命令一样；Windows 没装 Git 就先装 Git for Windows。

### 方式 B：下载 ZIP（不想装 git）

浏览器打开：
```
https://github.com/minzzj/DramaCore/archive/refs/heads/main.zip
```
解压到例如 `D:\DramaCore`。

> 下面统一用 `<DramaCore>` 表示解压/克隆后的仓库根目录。

## 2. 一键安装（推荐）

安装器会自动：检测 GPU/后端/显存 → 安装 ComfyUI 依赖 → 把插件与编排包放到正确位置 → 生成启动器。
**默认 dry-run 不写任何文件；确认后再加 `-Yes` / `--yes`。**

### Windows（PowerShell）

先看计划，不写入：
```powershell
cd <DramaCore>
powershell -ExecutionPolicy Bypass -File .\install\install_windows.ps1 `
  -Mode attach -ComfyUI "D:\ComfyUI" -DryRun
```

确认无误后正式安装：
```powershell
powershell -ExecutionPolicy Bypass -File .\install\install_windows.ps1 `
  -Mode attach -ComfyUI "D:\ComfyUI" -Yes
```

### Linux

```bash
cd <DramaCore>
chmod +x install/install_linux.sh
./install/install_linux.sh --mode attach --comfyui /opt/ComfyUI --dry-run
./install/install_linux.sh --mode attach --comfyui /opt/ComfyUI --yes
```

### macOS

```bash
cd <DramaCore>
chmod +x install/install_macos.sh
./install/install_macos.sh --mode attach --comfyui "$HOME/ComfyUI" --dry-run
./install/install_macos.sh --mode attach --comfyui "$HOME/ComfyUI" --yes
```

### 还没有 ComfyUI？用 bootstrap 模式

```powershell
# Windows：自动 clone/准备 ComfyUI 与 venv（不下载模型）
powershell -ExecutionPolicy Bypass -File .\install\install_windows.ps1 `
  -Mode bootstrap -ComfyUI "D:\ComfyUI" -Backend cuda -Yes
```
```bash
# Linux
./install/install_linux.sh --mode bootstrap --comfyui "$HOME/ComfyUI" --backend cuda --yes
```

安装成功后，仓库/ComfyUI 根目录会出现启动器：
- Windows：`start_dramacore.bat`
- Linux/macOS：`start_dramacore.sh`

以后启动 ComfyUI 用启动器（它自动设置 `BETTERCOMFYUI_HOME`），不要直接双击原版 `main.py`，否则插件找不到编排包。

## 3. 手动安装（一键安装失败时）

### 3.1 放插件

把 `<DramaCore>/bettercomfyui_comfy` 放到：
```
<ComfyUI>/custom_nodes/bettercomfyui_comfy
```
（目录名必须是 `bettercomfyui_comfy`，ComfyUI 用目录名当模块名。）

### 3.2 放编排包

`<DramaCore>/bettercomfyui` 可以留在仓库里，只要启动时设置环境变量：
```
BETTERCOMFYUI_HOME=<DramaCore 绝对路径>
```
- Windows：`setx BETTERCOMFYUI_HOME "D:\DramaCore"`（或写进启动器 .bat）
- Linux/macOS：`export BETTERCOMFYUI_HOME=/path/to/DramaCore`（写进启动器 .sh）

### 3.3 装依赖

用 **ComfyUI 自带的 Python** 安装：
```bash
<ComfyUI>/python -m pip install -r <DramaCore>/requirements.txt
```
依赖：`PyYAML / Pillow / numpy / imageio-ffmpeg / aiohttp`（torch、aiohttp 由 ComfyUI 本身提供）。

### 3.4 启动

```bash
set BETTERCOMFYUI_HOME=D:\DramaCore
python main.py
```

## 4. 模型文件（必须自己准备）

> ⚠️ 仓库**不包含任何模型权重**。以下文件名必须**完全一致**，否则工作流会显示「缺失模型」。

| 放到目录 | 文件名 | 用途 |
|---|---|---|
| `ComfyUI/models/diffusion_models/` | `minimax_h3_ref2va_pruned_int8_convrot.safetensors` | H3 主扩散模型 |
| `ComfyUI/models/text_encoders/` | `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors` | H3 文本编码器（34GB 级） |
| `ComfyUI/models/vae/minimax/` | `minimax_h3_video_vae_fp16.safetensors` | 视频 VAE |
| `ComfyUI/models/vae/minimax/` | `minimax_h3_audio_vae_fp32.safetensors` | 音频 VAE |
| `ComfyUI/models/loras/` | `minimax_h3_ref2v_turbo_8step_v1.0_768p_comfyui_bf16.safetensors` | 真实参数版 LoRA（8 步） |
| `ComfyUI/models/loras/` | `minimax_h3_ref2v_turbo_4step_v0.1_comfyui_bf16.safetensors` | 快速 4 步版 LoRA |
| `ComfyUI/models/checkpoints/` | `RealVisXL_V5.0_fp16.safetensors` | 素材图生成（SDXL；不生成素材可暂不装） |

说明：
- 快速 4 步版可以只装 4step LoRA；真实参数版用 8step LoRA；两个工作流共用主模型/文本编码器/VAE。
- 模型来源请走官方/授权渠道，遵守模型自身许可；本仓库只提供工作流，不代下载。

## 5. 配置 API Key

1. 复制配置示例：
```bash
cp config/user.yaml.example config/user.yaml
```
2. 编辑 `config/user.yaml`：
```yaml
prompt:
  endpoint: https://api.deepseek.com
  model_name: deepseek-chat
  api_key: '你的 Key'        # 不要提交到任何仓库
```
3. 也可以不改文件：启动后在 ComfyUI 右侧「剧核」面板里填写 API Key。
4. **`config/user.yaml` 已被 `.gitignore` 排除，禁止把真实 Key 写进工作流/截图/Issue。**

默认系统提示词：`h3_v3_contract`（V3.0 契约对齐，唯一提示词，37,505 字）。
默认「统一风格」是示例：`电影感，真实自然，自然光影，正常曝光，场景自适应`，**请按项目自行修改或替换**。

## 6. 启动并跑第一个片子

1. 运行启动器：
   - Windows：双击 `start_dramacore.bat`
   - Linux/macOS：`./start_dramacore.sh`
   - 或手动：设置 `BETTERCOMFYUI_HOME` 后 `python main.py`
2. 浏览器打开 `http://127.0.0.1:8188`，按 **Ctrl+F5** 强刷；
3. 加载工作流：
   - `bettercomfyui_comfy/workflows/【新版】剧核_单节点_剧本到成片_快速4步版_20261024.json`（测试/预览）
   - 或 `【新版】剧核_单节点_剧本到成片_真实参数版_20261024.json`（正式出片）
4. 节点首屏粘贴剧本 → 选择/新建项目 → 点画布顶部 **运行**；
5. 成片输出在 `ComfyUI/output/剧核成片/`（同时写项目目录）。

## 7. 升级

```bash
cd <DramaCore>
git pull
```
然后重新运行安装器（加 `-Yes` / `--yes`）或手动覆盖插件目录，重启 ComfyUI，Ctrl+F5 后重开【新版】工作流。
`config/user.yaml` 不会被覆盖，请自行保留。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 节点面板提示「编排包不可用」 | 启动时没设 `BETTERCOMFYUI_HOME`；改用 `start_dramacore.bat/.sh` 启动 |
| 工作流显示「缺失模型」 | 对照第 4 节文件名/目录，名字必须逐字一致 |
| 提示「参数与插件节点不一致」 | Ctrl+F5 强刷并重开【新版】工作流；本版会自动修复旧参数 |
| API 401 / 未配置 Key | 配置 `config/user.yaml` 或在「剧核」面板填写 |
| 显存不足 OOM | 降低分辨率/参考图数、`每批段数=1`、显存档位=低；48G 更稳 |
| 启动报端口占用 | 先关掉其他 ComfyUI 进程，或加 `--port 8189` |
| 安装器失败 | 回到安装器输出的最后一条报错；可加 `-KeepPartial` 保留现场，或按第 3 节手动安装 |
