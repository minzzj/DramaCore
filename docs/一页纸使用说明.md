> 目标：不懂技术也能看懂「打开哪个、点哪里、看什么、为什么看不到」。
> 完整细节在 [第一阶段总交付与总检查报告](第一阶段总交付与总检查报告.md)；
> 到 GPU 机器后的验收在 [SSH验收清单_剪辑完整性与画质](SSH验收清单_剪辑完整性与画质.md)。

## 先解决：为什么我"看不到"新节点/工作流

1. 节点与工作流确实已经装好了（当前 **24 个自建节点 / 17 套工作流**，其中 3 套 `00_` 开头）；
2. 打开/切换到 `http://127.0.0.1:8188` 后按 **Ctrl+F5** 强制刷新页面一次；
3. 左侧「工作流」菜单里找 **`00_【总流程】…`** 开头的三套；节点搜索框输入 `BetterComfyUI` 能看到全部节点。

---

## 三套「总流程」怎么选

| 你现在有什么 | 用哪套 | 能不能本机跑 |
|---|---|---|
| 只有一段剧本，想先看"全部内容"长什么样 | ① `00_【总流程】剧本→全部内容（本机可跑）` | ✅ 不需要 GPU/API Key（占位模式） |
| 已经有段视频（或别的 mp4），想做拼接/封装/审核 | ② `00_【总流程】段视频→剪好成片（本机可跑）` | ✅ 只要有 ffmpeg |
| 有 GPU + 图像模型 + H3 权重，要出真实成片 | ③ `00_【总流程】剧本→成片（GPU）` | ❌ 需要 GPU |

## ① 剧本 → 全部内容（本机可跑）

![剧本→全部内容](images/流程图_01_剧本到全部内容.png)

**4 步**：打开工作流 → 在「一体化总控台 → 剧本」粘贴剧本 → 点「运行/队列」→ 看右侧 5 个预览。

- 「使用占位结果」保持**开**：不用 API Key，首行会标"占位"，能看到完整结构；
- 想真实生成提示词：先在右侧面板填 DeepSeek Key，再把开关关掉；
- 本机**不能出片**（没有 GPU），出片用第③套。

---

## ② 段视频 → 剪好成片（本机可跑，不需要 GPU）

![段视频→成片](images/流程图_02_段视频到成片.png)

**3 步**：把段视频绝对路径粘进「成片剪辑 → 段视频路径列表」（每行一个）→ 点队列 → 看 8 个预览。

> 省一步的小开关：路径列表可以留空，勾选「自动发现最新视频」+ 填时间窗（分钟），它会自动扫描输出目录里最近的 mp4 并在审计里列出实际用到的文件（不会悄悄拼错）。

它一次完成：
1. **拼接（剪辑）**：按顺序合并段视频（流复制，不重编码）；
2. **封装**：编码成最终 mp4（CRF 可调）；
3. **自检**：成片时长 vs Σ段（容差 2%）、计划段数、黑帧/冻帧/静音、质量四维、**占位检测**；
4. 成片路径**自动接给「视频审核」**：段级 R_seg + 边界 + 整片 R_full，给出结论与需返工段。

> 诚实边界：转场特效未实现（不暴露、不静默忽略）；"画质高不高"最终仍需人工抽检，
> 机器只提供可算的证据（JSON/审计里全都有）。

## ③ 剧本 → 成片（GPU 全链，需要显卡与模型）

![剧本→成片 GPU](images/流程图_03_剧本到成片GPU.png)

**准备（只做一次）**：面板填 DeepSeek Key；`CheckpointLoaderSimple` 选你的图像模型；
UNET/CLIP/VAE 选 H3 权重（已预填文件名）；机器满足显存要求。

**使用**：大节点粘剧本 → **分两段点队列**（先 ①② 组生成素材并审核；再 ③④⑤ 组出片+剪辑+审核）。
> 也可以让脚本自动分两段跑（可选）：`python -B scripts/staged_run.py --project 我的短剧 --free-between`（段间自动 /free；显存峰值仍需用 vram_monitor 实测确认 <30.5GB）。
这是为了把显存压在 **32GB 以下**（生产环境 5090-32G 的红线，详见报告第七节）。

## 常见问题

| 问题 | 回答 |
|---|---|
| 点队列报"没有 API Key" | 面板填 Key；或本机先用①套的占位模式看结构 |
| 素材生成分支报错 | 需要在 `CheckpointLoaderSimple` 选一个已安装的图像模型（空值会明确报错） |
| 视频审核首次点队列报错 | 视频路径为空；第②套会自动填，第③套从 SaveVideo 输出目录复制 |
| 显存 OOM | 分两段跑（Ctrl+M 静音另一组）；生产先 720p + tiled VAE + `--reserve-vram 1.5` |
| 真的剪辑过吗？完整吗？质量高吗？ | 看「剪辑审计 / 完整性JSON / 质量JSON」，或按 SSH 验收清单跑命令 |
