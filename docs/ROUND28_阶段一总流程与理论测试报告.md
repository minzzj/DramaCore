## 一、交付：两套「总流程」工作流（普通用户只需要认这两套）

### 1. `00_【总流程】剧本→全部内容（本机可跑）`（8 节点 / 8 连线）
用途：**人工粘贴一段剧本 → 全部内容可见**（本机无 GPU 也能用）。
内容：剧本输入（大节点，可开/关占位）→ 分镜脚本 / 提示词JSON（E1–E5+导演组）/
素材清单 / 审计报告 / API 配置状态，共 5 个预览框。
左侧有 900+ 字中文说明区，4 个分组标题。

### 2. `00_【总流程】剧本→成片（GPU）`（26 节点 / 29 连线，6 个分组）
用途：**第一阶段完整链**（需要 GPU 与模型）。
链路：配置+剧本 → 素材生成→入库→素材审核 → 导演台→出片 → 视频审核 → 结果预览。
左侧说明区含：使用前准备（API Key / 图像模型 / H3 权重 / 显存要求）、三步操作、
视频审核用法、**显存分两段跑提示**（见第三节理论结论）。

> 说明：用户反馈「看不到工作流/新增节点」——实测 ComfyUI 服务里 23 个节点与 16 套工作流都在；
> 看不到通常是页面未刷新（需 Ctrl+F5）或未重启。本报告附复现命令。

## 三、理论测试（不依赖 GPU 的部分）

### 3.1 模型清单核对（GPU 流程引用的权重是否真在磁盘）
| 节点 | 文件 | 存在 |
|---|---|---|
| UNETLoader | minimax_h3_ref2va_pruned_int8_convrot.safetensors | ✅ |
| LoraLoaderModelOnly | minimax_h3_fl2v_lightx2v_turbo_4step…bf16.safetensors | ✅ |
| CLIPLoader | qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors | ✅ |
| VAELoader | minimax_h3_video_vae_fp16.safetensors | ✅ |
| VAELoader | minimax_h3_audio_vae_fp32.safetensors | ✅ |
（图像模型 CheckpointLoaderSimple 是空值 —— 必须由用户在 GPU 机器上选自己的模型，这是**已知未验证项**。）

### 3.2 显存理论峰值（沿用磁盘实测体积）
| 场景 | 显存需求 | 5090 32GB（预留 2GB = 30GB） |
|---|---|---|
| H3 全链一次性加载 | 19.53 + 14.61 + 4.85 + 0.56 = **39.55 GB** | ❌ 装不下 |
| 图像模型（估 SDXL 级 6.5GB）+ H3 同驻留 | ≈ **46.05 GB** | ❌ 必然 OOM |
| 分两段（先图后视频，切换前卸载） | max(39.55, 6.5) ≈ **39.55 GB** | ❌ 仍超过 30GB |
| 阶段化（ROUND20 方案：UNET 与文本编码器分阶段） | 峰值 **24.94 GB** | ✅ 余 5.06GB |

**结论（写进 GPU 工作流说明区）**：
* 同一张图一次点队列 = 图像模型 + H3 同时驻留 → 32GB 卡 OOM；
* 现阶段请「分两段跑」（静音另一组后点队列）；
* 第二阶段做自动阶段化调度（`/free` 切换 + 批量生成），峰值可降到 24.94GB。

### 3.3 任务量与耗时（第一阶段 1 小时片长理论）
| 项 | 估算 | 依据 |
|---|---|---|
| 段数 | 约 360 段（10s/段） | 逻辑图 ui_diagram_08 |
| 视频生成 | ≈360 次起步，返工另计 | 同上 |
| 审核（段级） | ≈360 次起步，新版本另计 | 同上 |
| 边界验证 | ≈360 次 | 同上 |
| 模型加载次数 | 阶段化 5 次 vs 逐段交替 22 次（10 段样本） | ROUND20 实测/理论 |
| 成片体积 | 1080p24 CRF18 一小时 ≈3.52–5.27GB（给区间） | ROUND20 理论 |

> 以上为**理论/外推**，必须在目标机实测校准，不作为"已验证"。

### 3.4 本地无法证明、必须上机实测的清单
1. 图像模型真实生成素材图（S3 全链）——本机无图像权重；
2. H3 真实出片（显存/内存/耗时/失败恢复）；
3. 视频审核在真实成片上的评分有效性（本地只用合成视频验证了流程与数值非恒定）；
4. 分两段跑的实际显存峰值是否如理论（24.94GB）——需 `nvidia-smi` 实测；
5. SSH 目标机的 ComfyUI 版本/路径/模型是否与工作流一致。
