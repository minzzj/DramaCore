## 三、成片剪辑闭环（逻辑图 SG6 的落地）

新增节点 **`成片剪辑+封装+自检`**（`BetterComfyUIFinalize`）：

1. **拼接（SPLICE）**：多段视频按顺序 concat（流复制不重编码，复用 `pipeline.splice`）；
2. **封装（ENC）**：按配置编码最终 mp4（CRF/格式/音轨，复用 `pipeline.encode`）；
3. **自检（证据化）**：
   - 完整性：成片时长 vs Σ段（容差 2%）、计划段数、音轨有无；
   - 剪辑性：黑帧/冻帧/静音段检测；
   - 质量：本地启发式四维（叙事流畅/音画同步/节奏合理/无明显跳变）；
   - **占位检测**：码率/画面过低 → 明确标"疑似占位，不是真实生成"（防止占位冒充）。
4. 成片路径**自动接给视频审核**，同一队列完成段级 R_seg + 整片 R_full；
5. 可选「自动发现最新视频」：路径列表留空时扫描输出目录最近 N 分钟的 mp4，审计里列出实际用到的文件（不悄悄拼错）。


真机证据（本机 CPU 模式，用 ffmpeg 合成 3 段 2.0/3.0/2.5s 测试视频）：
```
status=success；成片 7.54s（Σ=7.5s，通过）；段数 3 通过；完整性 passed；
黑帧0/冻帧0/静音0；报告 JSON 落盘；视频审核结论+整片 R_full 输出 → 8/8 PASS
```
诚实边界：转场特效未实现 → **不暴露、不静默忽略**；"画质高不高"最终仍需人工抽检，
节点只给机器可算的证据（审计里写明）。

## 六、本地理论测试（无 GPU 能证明的部分）

1. **模型清单核对**：GPU 流程引用的 5 个 H3 权重文件全部在磁盘（19.53/14.61/4.85/0.56/0.29GB）；
   图像模型 `CheckpointLoaderSimple` 为空 → 必须你在 GPU 机器上选；
2. **显存账**：H3 全加载 39.84GB；图像模型+H3 同驻留 ≈46GB；**32GB 装不下全加载** →
   必须分阶段；分阶段峰值理论 24.94GB（<30GB 红线）；
3. **任务量理论**：1 小时片 ≈360 段；360 次生成起步（返工另计），审核/边界各 ≈360 次；
   模型加载次数：阶段化 5 次 vs 逐段交替 22 次（10 段样本）；
4. **成片体积**：1080p24 CRF18 一小时 ≈3.52–5.27GB（区间）；
5. 详细见 `docs/ROUND28_阶段一总流程与理论测试报告.md`。

## 七、32GB 显存控制方案（生产 5090-32G）

| 阶段 | 驻留 | 峰值 |
|---|---|---|
| A 文本编码 | 文本编码器 14.61 + 激活 | ≈16GB ✅ |
| B 视频扩散 | UNET 19.53 + LoRA 0.29 + VAE 5.41 + 激活 3–5 | **28–30.5GB** ⚠️（贴线） |
| 1080p | 更高激活 | 30–34GB ❌ 高风险 |

落地：ComfyUI 启动 `--reserve-vram 1.5`；`PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True`；
VAE 一律 tiled；batch=1；**生产先 720p**；分两段跑；全程 `nvidia-smi` 采样，>30.5GB 判失败回退。
（第二阶段做自动阶段化调度后，这些手动步骤会消失。）

## 八、双卡效率/质量与测试机情况

| 项 | RTX 4090 48GB（测试） | RTX 5090 32GB（生产） |
|---|---|---|
| 算力/带宽 | 660 TFLOPS FP8 / 1008GB/s | 838 TFLOPS FP8 / 1792GB/s（≈1.27×/1.78×） |
| FP4 文本编码器 | ❌ 需 FP8/int4/CPU 回退 | ✅ 原生 NVFP4 |
| 全模型常驻 | 39.84+激活≈44–46GB（贴线可行） | ❌ 必分阶段（峰值 24.94GB 方案） |
| 效率（理论） | 基准 | **1.4×~1.7×**（文本编码阶段可能更快），分阶段重加载开销 ~1.5–2%/批 |
| 质量 | 同一权重/参数 → 等价；差异仅文本编码精度路径，需 PSNR/SSIM 验证 | 同左 |

**测试机（4090-48G）最大风险**：NVFP4 文本编码器在 Ada 上无硬件 FP4 支持，
可能要 dequant（BF16 64GB 必爆）或换 FP8（≈32GB）或放 CPU（需 64GB 内存）。
**请预装前确认三选一**，否则测试机只能验证流程、不能验证真实效率与质量。

**租机情况**：平台已定位（极智算 `https://www.jygpu.com/`，Edge 历史里有 console 页面）。
自动购买受"登录态/库存/支付确认"限制，本轮未擅自完成支付；**按你的话：不行就暂停，等你早上开**。
